Shafqat Group Poultry Services — Offline Khata starter

Files:
- index.html: Urdu offline khata prototype.
- Includes customers, customer ledger, credit entries, received payments, automatic balance, search, reports, and JSON backup/restore.

Important:
This is a working web-app prototype, NOT an APK yet. It stores data in the browser's local storage, so clearing browser data or uninstalling/removing its wrapper may lose data. Export regular backups. To produce a reliable Android APK, it must be packaged with an Android wrapper/build service and tested on a device.

Test: open index.html in a modern browser. For best results keep using the same browser/profile.
